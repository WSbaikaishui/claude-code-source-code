# 🎯 Claude Code 极简图解（小白版）

> 看完这 6 张图，你就知道 Claude Code 是什么、怎么工作的。
>
> 不需要任何编程知识。你奶奶也能看懂。

---

## 图1: 它是什么？

你坐在电脑前，打开一个黑色窗口，跟一个AI助手聊天。你说"帮我改一下代码"，它就真的去改了。

```mermaid
graph LR
    A["🧑 你"] -->|说话| B["🤖 AI助手"]
    B -->|看文件| C["📁 你的文件"]
    B -->|跑命令| D["💻 你的电脑"]
    B -->|回复你| A
```

> Claude Code 就像一个住在你电脑终端里的AI程序员。你用文字告诉它要做什么，它就会动手帮你做——能读文件、改代码、执行命令，然后告诉你结果。

---

## 图2: 你说一句话，它做了什么？

你说"帮我修一下这个问题"，然后经历了这些步骤：

```mermaid
graph LR
    A["🧑 你说话"] --> B["📨 接收消息"]
    B --> C["🧠 AI思考"]
    C --> D["🔧 动手干活"]
    D --> E["🔒 安全检查"]
    E --> F["💬 告诉你结果"]
    F -->|没做完| C
```

> 1. 你在窗口里打了一句话
> 2. 程序收到了你的话
> 3. AI 想了想该怎么做
> 4. AI 挑了个工具去执行（比如打开文件、改代码）
> 5. 系统检查一下这个操作安不安全
> 6. 把结果告诉你。如果事情没做完，它会继续想、继续做，直到搞定。

---

## 图3: AI 手里有什么工具？

```mermaid
graph TD
    A["🤖 AI助手"] --> B["📁 文件相关<br>读、写、改、搜索文件"]
    A --> C["💻 执行命令<br>就像你自己在终端打命令"]
    A --> D["🌐 上网查资料<br>搜索和打开网页"]
    A --> E["🤝 叫帮手<br>复杂任务分给小助手"]
```

> AI 不能凭空变出结果，它要通过"工具"来干活。就像厨师要用刀和锅，AI 也要用这些工具来操作你的电脑。

---

## 图4: 它怎么记住我们聊了什么？

AI 的记忆有大小限制，就像桌子只有这么大。聊多了就放不下了。

```mermaid
graph TD
    A["🗣️ 聊天越来越长"] --> B{"桌子放不下了"}
    B -->|方法1| C["📦 旧的打包压缩<br>保留重点"]
    B -->|方法2| D["📝 写便签备忘<br>下次能想起来"]
    B -->|方法3| E["🗑️ 太久的扔掉<br>只留关键信息"]
```

> AI 的"记忆"有大小限制，就像桌子只有这么大。聊多了就放不下了，所以它会把旧的内容压缩总结、写备忘录、或者扔掉不重要的，腾出空间继续聊。

---

## 图5: 安全吗？会不会乱搞我的电脑？

每次 AI 要做点什么，都要过三关：

```mermaid
graph TD
    A["🤖 AI要做一件事"] --> B["🚦 第1关：这个操作允许吗？"]
    B -->|允许| C["👮 第2关：危险操作要你亲自批准"]
    C -->|批准| D["🏠 第3关：只能在指定范围内活动"]
    D --> E["✅ 执行"]
    B -->|不允许| F["❌ 拒绝"]
    C -->|不批准| F
```

> 放心，AI 不会乱来。每次要做点什么都要过三关：首先看规则允不允许，然后危险操作必须你点头同意，最后它也只能在你给定的范围里活动。你可以理解为：它是个实习生，干什么都要你签字。

---

## 图6: 复杂任务怎么办？

遇到大任务，AI 会像项目经理一样把活分出去。

```mermaid
graph TD
    A["🧑 你: 帮我重构整个项目"] --> B["🤖 主管AI"]
    B --> C["🔍 调研员<br>先去看看代码"]
    B --> D["📐 规划师<br>制定方案"]
    B --> E["👷 施工员<br>动手修改"]
    B --> F["✅ 质检员<br>检查结果"]
    C --> B
    D --> B
    E --> B
    F --> B
```

> 遇到大任务，AI 会像项目经理一样把活分出去：先派人去调研现状，再让人制定方案，然后安排人动手，最后还有人检查质量。这些"小助手"各有分工，做完后向主管汇报。

---

## 一句话总结

**Claude Code = 一个住在你电脑终端里的AI程序员，你告诉它做什么，它就用各种工具帮你做，做之前会问你同不同意，做完了告诉你结果。**
